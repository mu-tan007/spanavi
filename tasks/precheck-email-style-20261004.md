## 2. 新規メールか、返信か

- **全件がアポ取得報告スレッドへの返信**。新規メールで送った事前確認・リスケ・キャンセルの報告は見つからなかった。
- 件名は「Re: 【アポイント取得のご報告】…」（ブティックスは「Re: RE: 【アウトバウンド外注】…」）のまま変えない。

- 宛先は、そのスレッドで最後にやり取りした担当者（ブティックスは担当確定メールの送り主の中村様、または三輪様）。

## 3. 共通の型

```
{姓}様                         ← 姓だけ＋「様」。フルネームは初回報告だけ
（空行）
お世話になっております。
（空行）
{本文 1〜3段落}
（空行）
{締め1行}
（空行）
{署名}
```

- **名乗りは入れない**（「Spartiaの篠宮でございます」は初回のアポ取得報告にしか無い）。例外は社外の新しい相手に初めて送るときだけ。
- 宛名の表記は相手の署名に合わせる（高野様は本人署名が「髙野」。同じ人に「高野」と「髙野」が混ざった例があるので、下書きでは相手の署名の字に揃える）。
- 署名：返信で相手の連絡を受ける形は「Spartia 篠宮」、こちらから報告を出す形は「篠宮」だけが多い。古い例に「MASP 篠宮」「SP 篠宮」、長い署名ブロックもあるが、**新しい下書きは「Spartia 篠宮」に統一**してよい。
- 締めは次のどれか1行（または2行）。
  - 完了：「当日はご対応のほどよろしくお願い申し上げます。」
  - 依頼を含む：「お忙しいところ恐れ入りますが、何卒よろしくお願い申し上げます。」
  - 直前の変更・キャンセル：「直前のご変更となり誠に恐れ入りますが、何卒よろしくお願い申し上げます。」
  - 通常：「何卒よろしくお願い申し上げます。」／「引き続き、何卒よろしくお願い申し上げます。」

## 4. 種類別の型と原文

### 4-1. 事前確認完了の報告

順序：① 「{社名}様への事前確認が無事に完了いたしました。」 → ② 付記（あるときだけ。「なお、」「また、」で始める） → ③ 締め。

付記の中身は、面談リンクの送り先の指定・変更、オンライン限定、財務資料の可否、携帯番号の共有、開始時刻の希望など。付記が無ければ2文で終わる。

原文（最小形・最多）
```
新井様

お世話になっております。

株式会社西原資源様への事前確認が無事に完了いたしました。

当日はご対応のほどよろしくお願い申し上げます。

篠宮
```

原文（付記あり・リンク送付先の依頼）
```
松岡様

お世話になっております。

原口水産様への事前確認が無事に完了いたしました。
なお、以下のアドレスおよび携帯番号宛に、再度オンライン面談のリンクをお送りいただきたいとのことでございます。

　メールアドレス：（伏せ）
　電話番号：（伏せ）
　※以前共有していたメールアドレスとは別のアドレスでございます。

お忙しいところ恐れ入りますが、何卒よろしくお願い申し上げます。

篠宮
```

原文（つながらなかった後の完了・続報）
```
塚本様

お世話になっております。五月雨式のご連絡失礼いたします。

先ほど、先方様にお電話が繋がり、無事に事前確認が完了いたしました。
なお、今回はオンラインでのみご対応が可能とのことでしたので、恐れ入りますが、記載のメールアドレス（伏せ）宛にオンライン面談のリンクをお送りいただけましたら幸いでございます。

当日は何卒よろしくお願い申し上げます。

篠宮
```

つながらない途中報告（クライアントから催促があった、または面談が近いとき）
```
多田様

お世話になっております。

本件の事前確認につきまして、昨日・本日にお電話をいたしましたが、いずれも社長様につながっておりません。
明日朝に再度ご連絡を差し上げ、事前確認を確定させていただければと存じます。

お待たせしてしまい誠に申し訳ございません。
何卒よろしくお願い申し上げます。

篠宮
```
→ 翌日の完了報告は「大変お待たせいたしました。本件の事前確認が無事に完了いたしました。」で始める。

### 4-2. リスケの報告

場面が4つある。どれも「事情（先方様より〜とのこと）→ 新しい日時 → クライアントへの確認または次の動き → お詫び・締め」の順。

(a) 先方都合で日時変更を打診する（クライアントの都合をまだ聞いていない）
```
髙野様

お世話になっております。

本件事前確認が遅くなりまして申し訳ございません。
先方様より、明日急遽外せないご用事が入られてしまったとのことで、10月12日（月）11時にて再調整していただきたいとのご要望を賜っております。

高野様のご都合のほどはいかがでしょうか。

直前のご変更となり誠に恐れ入りますが、ご確認のほどよろしくお願い申し上げます。

Spartia 篠宮
```
- インターンが先方と新日時を決めてきても、文面は「先方様のご要望を賜っております」＋「{担当}様のご都合のほどはいかがでしょうか」で**クライアントの了承を取る形**にする。「確定しました」とは書かない。

(b) 調整中の報告（新日時が未定）
```
舟山様

お世話になっております。

株式会社カードックHIRO様でございますが、急遽ご面談日に出張が入られてしまったとのことで、現在リスケジュール先の調整中でございます。
調整が完了しましたら速やかにご報告申し上げます。

直前のご変更となり恐れ入りますが、何卒よろしくお願い申し上げます。

篠宮
```

(c) リスケ完了の報告
```
北村様

お世話になっております。

社会保険労務士法人勝田事務所様のリスケジュールが無事に完了いたしました。
10月19日（月）13:00 にてお願いできればと存じます。

先方様へのオンライン面談のリンクのご共有のほど、よろしくお願い申し上げます。

篠宮
```
```
舟山様

お世話になっております。

取り急ぎ、本件のリスケジュールが完了いたしました。
10月17日（土）11時にてお願いいたします。カレンダーにも反映済みです。

（以下略）
```

(d) クライアント都合のリスケ依頼を受けたとき（受け付けの返信）
```
新井様

お世話になっております。

承知いたしました。18日（金）10:00-12:00もしくは15:00以降にて、先方様へ日程変更のご相談をいたします。
ご調整が難しい場合は、28日以降で再度候補を頂戴のうえ調整いたします。

本日中に先方様へご連絡し、回答が得られ次第、直ちにご一報申し上げます。

何卒よろしくお願い申し上げます。

Spartia 篠宮
```
- こちらの不手際（クライアントの予定と重ねた等）が原因なら、冒頭に「また、すでに予定が入られている箇所に調整をしてしまい、誠に申し訳ございません。」のように**具体的にお詫び**する。
- 打診が不調のときは「9月は当初の日程以外はご都合が合わないとのことでした。そのため、来週再度お電話をし、10月に再調整させていただく運びとなっております。」と、次の動きと時期を書く。

### 4-3. キャンセルの報告

順序：① 先方の理由（「先方様より〜とのことで」）→ ② キャンセルの結論（日時を添える）→ ③ お詫び → ④ 締め（必要なら今後の姿勢を1文）。

原文（先方から辞退）
```
新井様

お世話になっております。

本件につきまして、先方様よりやはり今回はM&Aのお話は聞く気になれないとのことで、キャンセルのご要望を賜っております。
つきましては、9日（水）16:00からのご面談はキャンセルにてお願いできればと存じます。

直前のご変更となり誠に恐れ入りますが、何卒よろしくお願い申し上げます。

篠宮
```

原文（事前確認の電話で判明）
```
三輪様

お世話になっております。

株式会社白石工務店様に事前確認のご連絡を差し上げましたところ、あいにく練馬区の工事の現場が始まり、非常に多忙で時間が取れなくなってしまったとのことで、明日のご面談はキャンセルとさせていただければと存じます。
立て続けのキャンセルとなり、深くお詫び申し上げます。

何卒よろしくお願い申し上げます。

篠宮
```

原文（リスケを試みたが不調）
```
塚本様

お世話になっております。

本件につきまして、先ほど先方様にリスケジュールの打診をさせていただきましたところ、あいにく他のご日程ではご都合がつかず、なおかつやはりM&Aに関する検討も現時点では厳しいとのことで、キャンセルとなりました。
スケジュールを調整いただいていた中、誠に申し訳ございません。

引き続き、優良企業様のアポイントを取得できるよう尽力してまいります。
何卒よろしくお願い申し上げます。

篠宮
```

原文（クライアントからキャンセル指示を受けた返信）
```
林様

お世話になっております。

承知いたしました。当該のアポイントにつきましては、キャンセルとさせていただきます。
本件につきましてはご期待に沿えず、誠に申し訳ございません。

引き続き、何卒よろしくお願い申し上げます。

Spartia 篠宮
```
- 理由を聞かれたら（フラーレン高野様の例）：「当該日時以外での再設定やオンラインでの実施もご提案いたしましたが、当面はやはり新たな面談を増やすお考えになることができないとのことで、今回は見送りとなった次第でございます。一定期間を置いて改めて接触を図り、状況に変化がございましたら直ちにご一報申し上げます。」

## 5. 言い回しの癖

- よく使う語：「無事に」（完了・リスケ完了にほぼ必ず付く）、「先方様」、「〜とのことで」「〜とのことでございます」、「ご要望を賜っております」、「あいにく」、「急遽」、「直ちに／速やかにご一報申し上げます」、「〜いただけましたら幸いでございます」、「五月雨式のご連絡失礼いたします」（同じスレッドで続けて送るとき）、「本件につきまして」、「弊方」（自社の不手際を言うとき。「当社」は使わない）。
- 敬語の度合い：最上位の謙譲・丁重語（申し上げます・賜る・頂戴）。先方企業の行動には尊敬語を重ねる（「入られてしまった」「お戻り」「ご都合」）。
- 文の長さ：1文に理由と結論を「〜とのことで、〜」でつなぐ長めの1文＋短い締め。本文は1〜3段落、全体で3〜8行。箇条書きは連絡先を並べるときだけ（全角スペースで字下げ）。
- 日時の書き方：「10月12日（月）11時」「10月19日（月）13:00」「9日（水）16:00から」。曜日を必ず括弧で添える。全角の括弧。
- 使わない表現：「当社」、絵文字、「！」、「取り急ぎご連絡まで」で終える書き方、インターン名（アポインター名は書かず「先方様より」「アポインターに対して」まで）、クライアントの社内事情への言及、「確定しました」の早書き（クライアントの了承前）。
- お詫びは原因がこちらにあるときだけ具体的に（「弊方の確認不足により」「ご予定を十分に確認できておらず」）。先方都合のときは「直前のご変更となり誠に恐れ入りますが」でとどめ、過剰に謝らない。キャンセルが続いたときは「立て続けのキャンセルとなり、深くお詫び申し上げます。」。

## 7. 下書き生成AIに渡す指示文の案

```
あなたはSpartia株式会社 篠宮の代筆です。M&A仲介会社のクライアントへ、アポ先企業の事前確認の結果を報告するメールの返信下書きを作ります。
- 該当アポの【アポイント取得のご報告】スレッドへの返信として作る。件名・Ccは変えず、本文の下にGmail標準の引用を残す。
- 形：「{姓}様」→空行→「お世話になっております。」→空行→本文1〜3段落→空行→締め1行→空行→「Spartia 篠宮」。名乗りは書かない。
- 完了：「{社名}様への事前確認が無事に完了いたしました。」＋付記（メモにあるときだけ「なお、」で1〜2文）＋「当日はご対応のほどよろしくお願い申し上げます。」
- リスケ：「先方様より、〜とのことで、{新日時（曜日）}にて再調整していただきたいとのご要望を賜っております。」＋「{姓}様のご都合のほどはいかがでしょうか。」。新日時が未定なら「現在リスケジュール先の調整中でございます。調整が完了しましたら速やかにご報告申し上げます。」
- キャンセル：「先方様より〜とのことで、{日時}のご面談はキャンセルにてお願いできればと存じます。」＋お詫び1文。
- 直前の変更なら締めは「直前のご変更となり誠に恐れ入りますが、何卒よろしくお願い申し上げます。」
- インターンのメモの事実だけを使い、無いことは書かない。インターン名・「当社」・絵文字は使わない。自社は「弊方」。日時は「10月12日（月）11時」の形。
- インターンが「キャンセル」と書いていても、リスケの余地があればその旨を下書きの冒頭に注記し、むー様に判断を委ねる。
```
