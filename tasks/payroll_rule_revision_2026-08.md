# 報酬ルール改定（2026年8月分から）

## 背景
- 7月から「面談日を入れずにアポ登録」する運用が始まり、集計に日程未定アポが混ざるようになった（6月以前は0件、7月は25件）
- チームリーダーが2名（浅井・瀬尾）になり、副リーダーは廃止（現在0名）
- 確定後にクライアント都合のキャンセルが判明するケースがあり、確定値を動かせる必要がある

## 変更点

### 1. 面談日なしのアポを集計対象外にする
- [ ] `money.js` `calcMonthlyPayroll` の月判定から `|| a.getDate` フォールバックを外す（面談日必須）
- [ ] `calcReferralBonuses` の日付基準も同じ扱いに揃っているか確認
- [ ] `PayrollSelfDetailView` の同じフォールバックも外す
- 影響: 7月の確定値と今のデータの再計算結果が一致するようになる（現状は浅井 +176万・瀬尾 +66万の乖離）

### 2. リーダーボーナスをチーム合算・均等配分に（2026-08 以降のみ）
- [ ] 対象売上をチーム別ではなくリーダー全員の合算に変更
- [ ] 段階料率を現行の半分にした新テーブルを適用
- [ ] 原資をリーダー人数で均等割り
- [ ] `payMonth < '2026-08'` は旧ロジックのまま（過去月を再計算しても壊れないこと）
- [ ] 副リーダー枠は 2026-08 以降は計算しない

### 3. 確定後の再計算（後日キャンセル対応）
- [ ] `payroll_snapshots` に `recalculated_at` カラム追加（マイグレーション）
- [ ] 報酬画面に「再計算」ボタンを追加（確定は維持したまま金額だけ更新）
  - 固定する値: `team_name` / `role` / `rank` / `incentive_rate`（確定時のまま）
  - 更新する値: `monthly_sales` / `incentive_amt` / `team_bonus` / `total_payout`
  - `referral_bonus` は据え置き（支払済マークと連動するため）
- [ ] 実行前に差分プレビュー（誰がいくら増減するか）を表示して確認させる
- [ ] 請求書発行済みの月は「請求書の出し直しが必要」と警告を出す

理由: 現状の「確定解除→再確定」だと、現在のチーム編成・役職・累計ランクで全部引き直されるため、過去月の金額が編成変更で動いてしまう（7/31の編成変更で実際に発生）

### 4. 重複実装の解消
- [ ] `PayrollSelfDetailView` の役職ボーナス計算が `money.js` と別実装になっているので共通関数に寄せる

### 5. 検証
- [ ] `money.test.js` に新ルールのケースを追加（合算・均等割り・月による分岐・面談日なし除外）
- [ ] 8月分を実データで試算し、7月以前の確定値が変わらないことを確認
- [ ] commit & push（main）

## 決定事項
- 合算の範囲は「リーダーが率いるチームのみ」。無所属メンバーの売上は含めない（むー様確認済 2026-08-01）

## レビュー（2026-08-01 実装完了）

### 実装したもの
※ 「面談日ベースに統一」は作業中に別セッションが先に main へ入れた（`144f6a2`）。
  `salesMonthOf()` / `salesAmountOf()` に集約されており、アナリティクス側も直っている。
  こちらはその上に合算ルールと再計算を載せる形でリベース解決した。

- `money.js`
  - 月判定は面談日のみ（上流の `salesMonthOf` を利用）
  - `COMBINED_LEADER_TIERS`（旧テーブルの半分）と `COMBINED_LEADER_BONUS_FROM='2026-08'` を追加
  - `calcMonthlyPayroll` を月で分岐。2026-08〜は合算・均等配分、それ以前はチーム別の旧方式
  - 各行に `bonusBasis`（原資・料率・分割人数）を持たせ、明細画面がここを読むようにした
  - `parseTiers` を切り出して段階料率JSONの読み込みを共通化
- `PayrollView.jsx`
  - 「再計算」ボタンを追加。確定を維持したまま金額だけ更新する
  - 再計算時はチーム編成と役職を**スナップショットの値に戻してから**計算する（`snapshotMembers` / `snapshotRoleMap`）
  - 実行前に増減の一覧を出し、請求書格納済みなら出し直し警告を出す
  - 確定日とは別に再計算日時を表示
- `PayrollSelfDetailView.jsx`
  - 役職ボーナスの独自再計算をやめ `calcMonthlyPayroll` に統一
  - 確定済み月はスナップショットを優先表示（調整項目のみライブ加算）
  - 確定済みバナーを追加
- `RewardSettings.jsx`
  - 段階料率の保存先を `leader_bonus_tiers_combined` に変更。旧 `leader_bonus_tiers` は触らない
  - 副リーダー欄を「2026年7月以前のみ」と明示
- マイグレーション: `payroll_snapshots.recalculated_at` を追加
