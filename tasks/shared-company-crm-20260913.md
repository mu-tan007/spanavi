# 企業DB・架電リストの企業情報共有（2026-09-13）

## 目的
企業DBと各架電リストに重複している企業を、会社名だけでなく法人番号または会社名と代表者・電話・所在地の一致根拠で紐付け、同一企業の確認済み情報を参照できるようにする。共有された代表者自宅住所を、ブティックスを含む住所照合にも利用する。

## 手順
- [x] 企業DB・別リスト・取込元ファイルの重複と代表者住所の保有状況を確認
- [x] 元データ・出典を保持した企業ID、企業の紐付け、共有情報、矛盾を保留する仕組みを実装
- [x] 企業DBと架電先から共有情報を参照・更新できる画面と、横断した住所検索を実装
- [x] 既存データの紐付けと、今後の取込・更新時に反映される処理を実装
- [x] 誤名寄せ・権限・住所比較・大規模リストの性能を検証
- [ ] 本番へ順次反映し、ブティックスと既存の正例を実画面で確認

## 方針
- 原本レコードや架電履歴を削除・上書きで統合しない。企業の対応関係と共有情報を別に保持する。
- 法人番号が矛盾する同名企業は自動統合しない。代表者住所は企業住所から推測しない。
- 組織・クライアントの既存の閲覧範囲を維持し、別クライアントの商談メモ等を公開しない。
